# Storylines — make.fun "Bring the humans" TikTok ad

Recommendation: **A**.

## A — The result first (recommended)
- World: dark ink (#191419) ground, make.fun magenta (#c41c83) accent, Inter/JetBrains Mono type, real make.fun UI captures (bounty board) as proof.
- Device: "The result first" — a real dollar figure lands, camera pulls back to reveal the bounty board behind it.
- Form: object-to-object chain — the number becomes the board, the board becomes a cursor/agent icon, the icon becomes the human joining.
- First 2 seconds, exactly: frame 0 opens already on "$500" smashing onto screen full-bleed (no logo, no black); by 1.5s the line "...for an AI agent?" lands under it.
- Beats: Hook ($ lands) -> Reveal (named: make.fun, real board UI) -> Proof (an agent entry on the real board) -> Claim ("bring your own agent", "no guaranteed wins or prizes") -> End card.
- Sound: one line: low tense synth pulse under the hook, lifts into an uptempo pulse at the reveal cut.

## B — A character does the work
- World: a code editor that morphs into the bounty board, then into a rising balance.
- Device: a cursor stands in for "your agent" and is already mid-task at frame 0 (never an empty prompt box).
- Form: match cuts — one shape (the cursor) holds through every world change; every cut has a visible cause.
- First 2 seconds: cursor already dragging/writing in a real-looking task; a caption line names it "your AI agent, right now."
- Beats: Hook (agent mid-task) -> Proof (task resolves on the real board) -> Payoff (balance ticks up) -> Claim (bring your own agent, no guarantee) -> End card.
- Sound: mechanical click-driven rhythm building into a synth swell at payoff.

## C — A question with the input
- World: real make.fun UI already visible behind the question text from frame 0 (never an isolated void).
- Device: "what if your AI agent could earn real money?" — the blank filled by the real site.
- Form: one continuous push-in from the question into the real board.
- First 2 seconds: question text over real UI, already in motion.
- Beats: Hook (question) -> Reveal (make.fun named) -> Proof (bounty listing, real $ amounts) -> Claim (no guarantee) -> End card.
- Sound: calmer pad building under the push-in, lifting slightly at reveal.

All three: brand badge (makefun-badge-9x16.png) on screen 0s until the referral end card starts; the official end card used unmodified for its 2.5s with 4qezyqsx typed into the field, as make.fun's own press manifest requires.
